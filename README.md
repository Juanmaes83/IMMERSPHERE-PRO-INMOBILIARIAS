# Immersphere Pro Inmobiliarias

Web comercial premium de servicios visuales, marketing y comunicacion inmobiliaria para inmobiliarias, promotoras, constructoras, estudios de arquitectura, interioristas y decoradores.

Esta web es la entrada comercial del ecosistema Immersphere. Su funcion es explicar, posicionar y captar clientes para servicios de produccion visual, video, renders, webs premium, campanas, SEO/GEO, dossiers y branding.

No es el SaaS tecnico y no es el CRM interno.

---

## Rol dentro del ecosistema

Immersphere trabaja con tres piezas separadas:

1. **Immersphere Pro SaaS**
   - Repo: `https://github.com/Juanmaes83/immersphere-pro`
   - URL: `https://immersphere-pro.vercel.app`
   - Funcion: plataforma tecnologica multi-tenant para propiedades, tours, visor, leads, analytics, white-label, publicacion, embeds, QR e informes.

2. **Immersphere Pro CRM Leads**
   - Repo: `https://github.com/Juanmaes83/immersphere-pro-crm-leads.git`
   - GitHub Pages: `https://juanmaes83.github.io/immersphere-pro-crm-leads/`
   - Funcion: CRM comercial standalone para gestionar leads, scoring, pipeline, presupuestos, propuestas, objeciones, Document Hub y seguimiento.

3. **Immersphere Pro Inmobiliarias**
   - Repo: `https://github.com/Juanmaes83/IMMERSPHERE-PRO-INMOBILIARIAS`
   - Vercel: `https://immersphere-pro-inmobiliarias.vercel.app/`
   - GitHub Pages: `https://juanmaes83.github.io/IMMERSPHERE-PRO-INMOBILIARIAS/index.html`
   - Funcion: web escaparate de servicios de marketing, comunicacion y produccion visual inmobiliaria.

## Paquetes comerciales

La web comunica cuatro entradas comerciales orientativas:

- **Listing Boost**: para destacar una propiedad concreta y generar mas solicitudes cualificadas.
- **Premium Property Experience**: para viviendas premium, reformas o proyectos que necesitan una presentacion completa.
- **Developer Launch**: para promociones, obra nueva y lanzamientos de promotora.
- **Visual Growth Retainer**: para marcas que necesitan continuidad mensual en contenido, campanas y posicionamiento.

Cada paquete se adapta por alcance, material disponible y objetivo comercial.

## Stack

- HTML, CSS y JavaScript vanilla.
- Web estatica compatible con Vercel y GitHub Pages.
- Assets visuales y videos integrados en la propia web o via CDN externo.
- Formulario/CTA comercial sin backend nuevo en esta intervencion.

---

## Limites de producto

Este repo no debe convertirse en:

- SaaS tecnico.
- CRM interno.
- Plataforma de gestion de tours.
- Panel de propiedades.
- Backend de leads o analytics.

Puede mencionar el ecosistema Immersphere, pero su funcion principal es captar clientes para servicios visuales y marketing inmobiliario.
